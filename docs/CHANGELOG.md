# Changelog

All notable changes to NJ Player will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- **Quality Review, Playback Benchmarking & QA Matrix (Prompt 14)**:
  - `docs/BENCHMARK.md`: Automated performance benchmark tracking cold start to 1st frame, seek latency, CPU %, and memory usage across 5 standardized profiles (H.264 1080p, HEVC 10-bit 4K, 4K HDR, MKV multi-track, and FLAC audio).
  - `scripts/benchmark.ps1`: Automated PowerShell execution harness profiling process launch, memory, and seek latency metrics.
  - `docs/QA-CHECKLIST.md`: Comprehensive manual test matrix covering Windows 10/11, NVIDIA/AMD/Intel hardware decoding, high DPI scaling (100% to 200%), multi-monitor moves, broken/corrupted streams, and offline network behaviors.
  - Full codebase review: verified clean disposal of all Win32 handles and mpv contexts, no string concatenation on paths, bit-exact zero-allocation filters on bypass, and zero compile warnings in Release.
- **Packaging, Automated Release & Distribution (Prompt 13)**:
  - `installer/NJPlayer.iss`: Production Inno Setup script providing modern per-user installation into `{localappdata}\Programs\NJPlayer` without requiring administrative UAC elevation, Start Menu shortcut, optional Desktop icon, clean uninstaller, and user file associations for video (.mp4, .mkv, .avi, .webm, .mov) and audio (.mp3, .flac, .wav, .m4a, .ogg).
  - `scripts/build-release.ps1`: Automated packaging script compiling self-contained x64 Release builds (`dotnet publish`), packaging portable ZIP with `portable.flag`, and generating `SHA256SUMS.txt` cryptographic hashes.
  - `.github/workflows/build-and-release.yml`: Complete GitHub Actions CI/CD pipeline building, running tests, assembling artifacts, and publishing GitHub Releases on tag pushes (`v*`).
  - `THIRD-PARTY-NOTICES.txt`: Comprehensive license documentation covering libmpv (LGPL-2.1+), FFmpeg/ffprobe (LGPL/GPL), yt-dlp (Unlicense), radio-browser.info (ODbL), and .NET runtime (MIT).
  - `manifests/n/NahomMulualem/NJPlayer/1.0.0/`: Complete draft WinGet package manifests (version, installer, locale) ready for Windows Package Manager repository submission.
- **Online Radio Browser & Real-Time Audio Visualizer (`NJPlayer.Features` & `NJPlayer.App`)**:
  - `RadioBrowserService`: Community-driven radio directory client using `radio-browser.info` with dynamic DNS round-robin server resolution (`all.api.radio-browser.info`) and multi-mirror fallback (`de1`, `nl1`, `at1`).
  - Country filtering with **Ethiopia (ET)** pinned at index 0, followed by "All Countries" and global station queries.
  - Local JSON caching in `%APPDATA%\NJPlayer\radio_cache.json` providing resilient offline browsing and instant station search.
  - Real-time audio visualizers via mpv `lavfi-complex` filter generation:
    - `showcqt`: Constant-Q Transform frequency spectrum analyzer (1280x720, 30 fps).
    - `showwaves`: Live oscilloscope audio waveform with electric cyan accent token (`0x00E5FF`).
    - `off`: Bit-exact zero overhead mode for normal video or lightweight playback.
  - Stream resiliency & ICY metadata:
    - Added automated stream reconnects (`stream-lavf-o=reconnect=1,reconnect_streamed=1,reconnect_delay_max=5`) and 15-second network timeout.
    - Implemented mpv `media-title` property observation raising real-time events for live ICY/Shoutcast/Icecast track and station updates with on-screen notification toasts.
  - `RadioPanelWindow`: Modeless floating panel matching `DESIGN.md` Section 6 on `surface-raised` (`#1A212A`) with search box, country filter, favorites star toggle, bitrate badges, and play triggers.
  - Top-bar caption button `📻` in `ControlsOverlayWindow` for instant access.
  - Automated unit tests (`tests/NJPlayer.Tests/RadioTests.cs`) covering visualizer filter graphs, Ethiopia pinning, favorites persistence, and model formatting (78 total tests passed).
- **Lossless Trimmer & Online Downloader (`NJPlayer.Features` & `NJPlayer.App`)**:
  - `MediaTrimmerService`: Lossless stream-copy trimming (`-c copy -avoid_negative_ts make_zero`) executed via external `ffmpeg.exe` with `ProcessStartInfo.ArgumentList` and async progress parsing.
  - Optional frame-accurate re-encode mode (`libx264` + `aac`) when cuts between keyframes are required.
  - Hotkeys <kbd>I</kbd> and <kbd>O</kbd> to set In and Out points at current playback position with live preview seek.
  - Clear user messaging on keyframe snapping vs re-encoding.
  - `MediaDownloaderService`: Online video/audio downloader wrapping external `yt-dlp.exe` with format presets (Best Available, 1080p, 720p, MP3 Audio, Best Audio), download speed/ETA regex parsing, and non-blocking cancellation.
  - Prominent terms of service & responsibility notice for downloaded media.
  - Auto-play: Automatically loads and starts playback of downloaded videos when finished.
  - `TrimmerWindow` & `DownloaderWindow`: Floating dark modals matching `DESIGN.md` on `surface-raised` (`#1A212A`) with progress bars and top-bar buttons (`✂` and `📥`).
  - Automated unit tests (`tests/NJPlayer.Tests/TrimmerAndDownloaderTests.cs`) covering validation, duration calculations, and process binary resolution (71 total tests passed).
- **Subtitle Suite, Ge'ez/Amharic Rendering & Keyless Downloader (`NJPlayer.Features` & `NJPlayer.App`)**:
  - `SubtitleService`: Automated detection of sidecar subtitle files (`.srt`, `.ass`, `.ssa`, `.vtt`, `.sub`), text encoding detection (UTF-8, UTF-16 LE/BE, UTF-32, Windows-1252), and track switching.
  - Ge'ez and Amharic script rendering: configured fallback font stack (`Nyala, Ebrima, Segoe UI`) ensuring complete Ethiopic Unicode (U+1200 - U+137F) coverage without missing glyphs or layout corruption.
  - Subtitle delay (<kbd>Z</kbd>/<kbd>X</kbd>) and font size customization (24px to 72px) applied live to mpv.
  - `SubtitleHashCalculator`: 64-bit OpenSubtitles chunk hash calculation computed asynchronously off the UI thread via `Task.Run` with cancellation.
  - `ISubtitleProvider` & `PodnapisiSubtitleProvider`: Free keyless online subtitle provider handling query searches, zip decompression, timeouts, and network errors gracefully.
  - `SubtitlePickerWindow`: Dark dialog on `surface-raised` (`#1A212A`) with track picker, local file browsing, font/delay controls, and online search results with one-click download.
  - UI & Airspace glitch fixes: native Win32 `ReleaseCapture()` + `WM_NCLBUTTONDOWN` caption dragging, `WM_WINDOWPOSCHANGED` hook for zero-lag overlay tracking, and hiding `PlayerHost` on empty state to prevent airspace punching.
  - Automated unit tests (`tests/NJPlayer.Tests/SubtitleTests.cs`) covering hash calculation, sidecar matching, Ge'ez UTF-8 detection, and provider error resilience (64 total tests passed).
- **Audio Suite & 10-Band Graphic Equalizer (`NJPlayer.Features` & `NJPlayer.App`)**:
  - `IAudioSuite` & `AudioSuiteService`: Modular audio processing engine built behind a lazy-loaded interface in `NJPlayer.Features`.
  - 10-band graphic equalizer with standard ISO center frequencies (31 Hz, 62 Hz, 125 Hz, 250 Hz, 500 Hz, 1 kHz, 2 kHz, 4 kHz, 8 kHz, 16 kHz) and -12 dB to +12 dB range using FFmpeg peaking biquad filters (`equalizer=f=...:width_type=o:w=1:g=...`).
  - Dedicated Bass Boost low-shelf filter (`bass=g=...:f=100`) and Treble high-shelf filter (`treble=g=...:f=3000`).
  - Night Mode using FFmpeg's Dynamic Audio Normalizer (`dynaudnorm=f=150:g=15:m=8:r=0.9`) for dynamic range compression that tames explosions and clarifies whisper dialogue during late-night viewing.
  - Zero-overhead bypass: bands at 0 dB and flat tone controls produce an empty filter string, keeping the audio path bit-exact.
  - Built-in genre presets (Flat, Rock, Pop, Jazz, Classical, Dance / EDM, Vocal Boost, Bass Heavy) switching dynamically to "Custom" on any slider interaction.
  - `AudioPanelWindow`: Modeless floating panel matching `DESIGN.md` Section 6 on `SurfaceRaisedBrush` (`#1A212A`) with vertical sliders, dB readouts, preset picker, Enable/Disable toggle, and "Reset to Flat" button.
  - Hotkey and UI integration: mapped to hotkey `E` (`CommandId.ToggleEqualizer`) and top-bar caption button `🎚`.
  - Per-user persistence: saved across sessions via `AppSettings.Audio` in `%APPDATA%\NJPlayer\settings.json`.
  - Automated unit tests (`tests/NJPlayer.Tests/AudioSuiteTests.cs`) covering lavfi filter chain generation, preset frequencies, boundary clamping, and reset state (58 total tests passed).
- **Settings, Resume Playback, Single-Instance IPC & File Associations (`NJPlayer.Core` & `NJPlayer.App`)**:
  - `AppSettings` & `SettingsManager`: JSON persistence (`settings.json`) with automatic detection of portable mode (`portable.flag` next to the executable directs storage to `./data/`; otherwise uses `%APPDATA%\NJPlayer`).
  - Resume playback per file: remembers playback timestamp if past 5 seconds and not in the final 5 seconds; automatically restores playback position upon reopening with on-screen toast confirmation and clears on natural completion.
  - Recent files history: deduplicated list with LRU ordering, capped at 15 items, displayed with clickable quick-open buttons directly on the empty-state overlay.
  - Single-instance IPC: robust named mutex (`Local\NJPlayer_SingleInstance_Mutex_Session`) combined with an asynchronous named pipe server (`NJPlayer_SingleInstance_Pipe_Session`) forwarding file paths and arguments from secondary launches to the primary window and bringing it to the foreground.
  - Command-line argument handling: supports media file paths, directories, URLs, and `--bench` flag for profiling cold start timing.
  - Window geometry memory: remembers window position, size, and maximized state across restarts, ensuring coordinates stay within visible virtual screen bounds.
  - `SettingsWindow`: Dark dialog on `surface-raised` (`#1A212A`) matching `DESIGN.md` with toggles for resume position, hardware decoding selector (`auto-safe`, `d3d11va`, `nvdec`, `no`), storage mode info, cache clear buttons, and Inno Setup file association script preview.
  - `FileAssociationHelper`: Generates safe Inno Setup registry script snippets for Windows Explorer integration without altering the developer's registry directly.
  - Automated unit tests (`tests/NJPlayer.Tests/SettingsTests.cs`) covering portable mode detection, AppData path resolution, 5-second boundary rules, recent files deduplication, and JSON roundtrip (51 total tests passed).
- **Playlist Drawer & Management (`NJPlayer.Core` & `NJPlayer.App`)**:
  - `PlaylistManager`: Independent managed playlist engine supporting recursive directory scanning, reordering, true Fisher-Yates shuffle, repeat modes (`None`, `RepeatAll`, `RepeatOne`), M3U/M3U8 import/export, and automatic persistence (`%APPDATA%\NJPlayer\playlist.json`).
  - `PlaylistDrawer`: 340px slide-in drawer on `SurfaceBrush` (`#12171D`) with 180ms cubic-bezier easing (`base`) overlaying the right side without resizing video.
  - 44px playlist rows with title, duration, drag handle, and cyan accent active indicator bar.
  - Drag-and-drop support: drop external media files/folders directly onto drawer or window, and drag-to-reorder items within the playlist.
  - Full-text instant search filtering playlist items in real time.
  - Right-click context menu: Play, Remove, Show in Folder, and Media Properties.
  - Auto-advance on end of file: automatically plays next track on `MpvPlayer.EndFile` (with EOF reason), respecting shuffle and repeat modes.
  - Automated unit tests (`tests/NJPlayer.Tests/PlaylistTests.cs`) covering collection mutations, reordering, repeat modes, shuffle, and M3U roundtrip (46 total tests passed).
- **Data-Driven Hotkey System & On-Screen Toasts (`NJPlayer.Core` & `NJPlayer.App`)**:

  - `HotkeyBinding` and `HotkeyManager`: Centralized keyboard gesture normalization, fast command dispatch, conflict detection, and JSON persistence (`%APPDATA%\NJPlayer\hotkeys.json`).
  - `ToastOverlay`: On-screen notification pill positioned bottom-center on `SurfaceRaisedBrush` (`#1A212A`) with 2.0s auto-hide timer, displaying feedback for volume %, speed, seek steps, subtitle delay, and system status.
  - `HotkeySettingsWindow`: Dark dialog on `surface-raised` with 12px corner radius (`lg`), drop shadow, live conflict detection banner, real-time key recording, and "Reset to Defaults".
  - Automated unit tests (`tests/NJPlayer.Tests/HotkeyTests.cs`) covering default spec hotkey coverage, modifier normalization, conflict detection, and JSON serialization (41 total tests passed).
- **Custom Seekbar & Hover Thumbnail Preview (`NJPlayer.App` & `NJPlayer.Core`)**:
  - `PlayerSeekbar`: Custom control matching `DESIGN.md` Section 4 with 4px background track (`BorderBrush`), buffered range track (`TextMutedBrush` at 35%), and played range track (`AccentBrush`).
  - Smooth 120ms grow-on-hover transition enlarging track from 4px to 8px and revealing a 14px cyan thumb.
  - Chapter gaps support rendering visual dividers for chapter markers along the track.
  - Hover preview popup with 160x90 thumbnail frame, 8px corner radius (`md`), shadow, and instant time label clamped inside window bounds.
  - `FfmpegThumbnailService`: Background extraction using external `ffmpeg.exe` via `ProcessStartInfo.ArgumentList` with low priority (`BelowNormal`), cancellation tokens, and 80ms debounce.
  - In-memory 5-second time bucket cache (`(filePath, bucket_N)`) preventing redundant process spawns and disk reads.
  - Live scrubbing with non-exact fast seeks during drag and a single exact seek on release.
  - Real-time seek latency stopwatch logging (`[NJPlayer Seek Latency]`).
  - Full keyboard support on seekbar (Left/Right for -/+5s, Shift+Left/Right for -/+1s, Ctrl+Left/Right for -/+30s) with visible accent focus ring.
  - Automated unit tests (`tests/NJPlayer.Tests/ThumbnailTests.cs`) covering 5-second time bucket logic and cache clearing (32 total tests passed).
- **Frameless Window & Airspace Controls Overlay (`NJPlayer.App`)**:
  - `Themes/Colors.xaml`: All design tokens from `DESIGN.md` (`BgBrush` `#0B0E12`, `SurfaceBrush` `#12171D`, `Surface85Brush` `#D912171D`, `AccentBrush` `#00E5FF`, `DangerBrush` `#FF5C6C`, typography, radii).

- **Video Host & Playback Integration (`NJPlayer.App`)**:
  - `VideoHost`: `HwndHost` subclass creating a Win32 child window with `WS_CHILD | WS_CLIPCHILDREN | WS_VISIBLE`, passing its handle (`wid`) to mpv for zero-copy native video rendering.
  - Video playback integration with `hwdec=auto-safe` (D3D11VA / NVDEC / VAAPI / Vulkan hardware decoding) and real-time active decoder query via `hwdec-current`.
  - Drag-and-drop support on `MainWindow` for instant video file loading.
  - Standard `Ctrl+O` hotkey and file picker dialog for opening media files.
  - `Space` hotkey for instant play/pause cycling.
  - Minimal telemetry and debug bar displaying active hardware decoder status (`hwdec`), file title, playback badge (`PLAYING` / `PAUSED`), and elapsed/total duration (`00:00 / 00:00`).
  - Empty state overlay with glowing logo emblem and clear drop instructions, plus graceful fallback banner with download instructions when `libmpv-2.dll` is not yet installed.
- **Core mpv Wrapper & Playback Engine (`NJPlayer.Core`)**:
  - `MpvNative`: P/Invoke signatures and struct definitions for `libmpv-2.dll` with 64-bit calling conventions.
  - `MpvContext`: SafeHandle wrapper managing `mpv_handle` life cycle, thread synchronization lock, and safe UTF-8 string array marshaling for `mpv_command` (zero string concatenation for paths).
  - `MpvOptionBuilder`: Pre-initialization builder for hardware decoding (`auto-safe`), keep-open, idle, terminal suppression, and window embedding (`wid`).
  - `MpvPlayer`: High-level engine exposing `Load`, `Play`, `Pause`, `TogglePause`, `Stop`, `Seek` (fast/exact), `SetVolume`, and `SetSpeed`.
  - Dedicated event-loop worker thread waking on `mpv_set_wakeup_callback` with an `AutoResetEvent` (zero CPU waste, zero tight-loop polling).
  - Synchronized observation of `time-pos`, `duration`, `pause`, `volume`, `speed`, and `track-list`.
  - Standard .NET events: `TimePositionChanged`, `DurationChanged`, `PauseChanged`, `VolumeChanged`, `SpeedChanged`, `TrackListChanged`, `EndFile`, and `Error`.
  - Unit test suite (`tests/NJPlayer.Tests/MpvLogicTests.cs`) covering option building, event mapping, time conversions, and command arguments formatting (20 tests passed).
- Master branding and multi-resolution Windows icon suite in `src/NJPlayer.App/Assets`:
  - `app.ico` containing 16x16, 32x32, 48x48, and 256x256 32-bit RGBA frames for Windows Shell compatibility.

  - `src/NJPlayer.Features`: C# class library for secondary features (subtitles, trimmer, downloader, radio, equalizer).
  - `tests/NJPlayer.Tests`: xUnit test project for core logic and architecture validation.
